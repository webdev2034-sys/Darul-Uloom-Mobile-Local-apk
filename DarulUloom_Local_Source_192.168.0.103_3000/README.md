## Build Local APK without installing Flutter
This package includes `.github/workflows/build-local-apk.yml`.
Fork/upload the project to GitHub, open Actions, run **Build Local APK**, then download the generated artifact.
The local API target is `http://192.168.0.103:3000/api/`.
